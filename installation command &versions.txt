# Project Setup and Dependencies

This document outlines the packages, their versions, and the commands required to set up, build, and run the `trustchain-platform` project.

## Global Dependencies

It's recommended to have Node.js and npm installed.

## Project Structure

The project consists of several sub-projects, each with its own `package.json`:

- `verifier-portal` (React application)
- `student-wallet` (Expo/React Native application)
- `blockchain` (Hardhat project for smart contracts)
- `university-portal` (React application)

---

## 1. `verifier-portal`

- @testing-library/dom: ^10.4.1
- @testing-library/jest-dom: ^6.9.1
- @testing-library/react: ^16.3.0
- @testing-library/user-event: ^13.5.0
- ethers: ^5.7.2
- html5-qrcode: ^2.3.8
- react: ^19.2.0
- react-dom: ^19.2.0
- react-scripts: 5.0.1
- web-vitals: ^2.1.4

### Dev Dependencies:
- cross-env: ^10.1.0

### Installation, Build, and Run Commands:
```bash
cd verifier-portal
npm install
npm run build

```
